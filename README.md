# 集物志 · 闲置交易与兴趣社区

这是一个校园生活与交易平台：生活广场提供朋友圈式动态、照片分享、点赞和留言；交易市集只支持商品买卖，并将搜商品、精确搜用户放在同一个搜索入口。点击用户可进入主页，查看对方在售好物、发布的动态，或发起私信。

前端现已迁移至 **Vue 3 + Vue Router 4 + Vite**，页面均为原生 Vue 单文件组件。后端沿用 **Express + MySQL**，继续使用原来的账号、数据库、文件上传目录和 API。

## 本地运行

1. 启动本机 `MySQL80` 服务。可双击项目原有的 `启动MySQL服务.bat`，该脚本需要你在 Windows 中确认管理员权限。
2. 保留已有 `.env` 配置；新环境参考 `.env.example` 设置数据库连接。
3. 在本目录运行 `npm install`，然后运行 `npm run dev:all`。也可双击 `启动项目.bat`。
4. 打开 http://localhost:5173 。前端将 `/api` 和 `/uploads` 转发到端口 3001。

单独启动前端：`npm run dev`；单独启动后端：`npm run dev:api`。

普通用户和管理员共用登录页，由服务端返回的身份决定可见功能。原有注册、密保找回密码和修改密码接口继续使用。

## 已迁移功能

| 入口 | 功能 |
| --- | --- |
| `/`、`/posts/:postId` | 朋友圈式动态、照片分享、点赞、热门排序、搜索、留言、删除自己的帖子 |
| `/plaza`、`/items/:itemId` | 商品 / 用户统一搜索、分类筛选、排序、分页、收藏、商品详情、立即购买 |
| `/warehouse` | 拍照或上传商品图、中文/英文印刷文字识别辅助填标题/分类/描述，发布、编辑、上下架、删除物品 |
| `/users/:userId` | 用户公开主页：头像、昵称、签名、在售好物、动态、发私信；不包含电话、地址和实名信息 |
| `/rentals`、`/orders/:requestId` | 我卖出的 / 我买到的，模拟支付、接单、发货、签收、退款及记录移除 |
| `/chat` | 私信会话、文本、图片 / 文件、撤回、移除会话 |
| `/profile`、`/favorites` | 资料、头像、实名绑定 / 解绑、收藏管理 |
| `/books`、`/borrowed`、`/add` | 管理员保留旧图书资料和历史记录，停止新增借阅；普通用户的旧链接转到交易市集图书分类 |
| `/batch` | Excel / CSV 导入、模板下载、字段选择及导出 |
| `/admin` | 用户账号、启停、角色调整、密码重置、退款仲裁、操作日志 |

新商品只需填写一个整件售价，不支持按天计价。已有明确一口价的旧商品沿用原一口价；只有旧租金的商品不会出现在交易列表，卖家需要在“我的发布”编辑确认售价。历史租借订单只读，原数据和原计价金额保留；有购买订单的商品不允许修改原售价。为兼容历史数据，内部仍保留 `rent_requests` 表名、`buyout` 类型及 `rented` 状态编码，界面统一呈现为交易和已售出。支付目前全部为模拟支付，不产生真实扣款。

## 性能和交互

- 页面使用动态导入；仅访问相应页面时下载页面代码。
- Excel 解析库仅在选择导入文件时下载，后台入口也不预先加载它。
- 保持统一导航外壳；社区、广场、收藏通过 `KeepAlive` 保持页面状态，返回列表恢复滚动位置。
- 有界、按账号隔离的 GET 缓存；可共享读取去重；修改数据后失效；快速切换筛选时取消旧请求，防止响应乱序覆盖页面。
- 页面只请求自己需要的数据，登录后不再全量获取图书、日志、用户等无关信息。
- 导航提示 20 秒同步，私信 5 秒同步；隐藏页面暂停轮询，离开聊天后清理定时器，避免请求堆叠。
- 列表分页渲染、图片延迟加载及固定占位、骨架屏、重试按钮、温和的页面过渡。
- 服务端开启响应压缩、上传文件缓存和数据库连接保活，请求日志改为可选的单行输出。设置 `LOG_REQUESTS=1` 开启，不记录请求体。
- 桌面侧边栏和手机抽屉导航；键盘焦点、弹窗 Escape 关闭 / 焦点恢复、消息反馈及减少动画偏好适配。
- 图片文字识别按需加载，识别中文/英文印刷文字；分类由常见词提供建议，不负责识别纯图像中的无文字物品。

构建体积对比、测试证据与当前限制见 [迁移验收说明](./docs/迁移验收说明.md)。

## 检查与构建

```sh
npm run lint
npm test
npm run build
npm run test:e2e
npm run test:marketplace
```

浏览器测试使用隔离的接口响应，不会操作真实数据库。Windows 默认使用已安装的 Edge；其他环境先执行 `npx playwright install chromium`。测试使用构建产物，因此先运行 `npm run build`。

`test:marketplace` 使用 `.env` 指定的 MySQL，在本机临时端口验证真实接口。仅创建隔离的测试账号、商品与订单，结束后按本次创建的编号清理，不重建数据库。请仅在开发/测试数据库运行。

`npm run preview` 用于本地检查生产构建。正式部署需将 `dist` 交由 Web 服务器托管、为 Vue 路由设置 SPA 回退，并将 `/api`、`/uploads` 反向代理到后端；不要把开发预览服务当作生产服务器。

## Linux 服务器部署

项目已提供 `Dockerfile`、`compose.yaml`、Nginx、Caddy 自动 HTTPS、MySQL 持久化和安全数据库引导配置。完整步骤见 [服务器部署指南](./deploy/README.md)。复制 `.env.production.example` 后替换所有占位密码，再运行 `docker compose --env-file .env.production up -d --build`。

## 目录与回退

- `src/pages`：Vue 页面。
- `src/components`：图标、卡片、弹窗、分页、空状态等共享组件。
- `src/api.js`、`src/composables.js`：请求、缓存、请求竞态控制、轮询及异步反馈。
- `src/styles.css`：配色、排版、响应式与动效。
- `tests`：请求层测试与浏览器测试。
- `docs/previews`：新界面的测试效果截图，使用演示数据。
- `react-backup-20261008`：迁移前的前端源码、依赖清单与锁文件、入口配置，以及修改前的后端入口和配置目录。

回退前先停止开发服务，将备份中的对应文件恢复到本目录，再运行 `npm ci`。备份未复制数据库、上传文件或 `.env`；这些数据在此次迁移中没有被重建或清空。

实现参考：[Vue 官方性能指南](https://vuejs.org/guide/best-practices/performance)、[路由懒加载](https://router.vuejs.org/guide/advanced/lazy-loading)、[KeepAlive](https://vuejs.org/guide/built-ins/keep-alive)。
